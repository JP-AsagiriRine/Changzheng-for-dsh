# 長征テーマ（changzheng V1）— DeepSeek Harness Web テーマプラグイン

DeepSeek Harness Web GUI 向けの黒・赤カラーテーマプラグインです。長征（Long March）の
赤星アイコンセットをモチーフとし、ブラウン管テレビ風エフェクトを備えています。
組み込みのライト/ダークテーマとは独立しており、**設定 → 一般 → 「長征テーマ · 黒紅」**
からワンクリックで有効/無効を切り替えられます。

## フォルダ構成

```
changzheng V1/
├── host.js            # Host 側（アイコンアセット供給 RPC）
├── client.js          # Client 側（テーマと全 UI カスタマイズ）
├── manifest.json      # プラグインマニフェスト（名前/バージョン/アイコン対応表）
├── README.md          # 中国語 README（オリジナル）
├── README_EN.md       # 英語 README
├── README_JP.md       # 本ファイル
├── README_Nya.md      # にゃー言語のイースターエッグ（meow のみ）
└── assets/            # テーマ用 PNG アセット 12 枚
```

## 別の dsh 環境へのデプロイ

### 1. ファイル配置

`changzheng V1` フォルダをそのままターゲット環境の**セッションワークスペースルート**
（例: `D:\dsh0\changzheng V1`）に置いてください。`assets/` 内の 12 枚の PNG は欠かさず
そろえます。

Host 側は次の順でアイコンを解決します（相対パスはセッションワークスペース基準）。

1. `changzheng V1/assets/`（同梱、推奨）
2. `main-changzheng/`（旧フォルダ互換）
3. `D:\dsh0\main-changzheng`（開発機の絶対パスへのフォールバック）

### 2. プラグイン登録

dsh Web GUI の動的プラグインインターフェースで登録します（新環境では `czthm` など
新しいセマンティックプレフィックスで構いません）。

```js
cordis_define({
  plugin: { kind: 'new', idPrefix: 'czthm' },
  name: '长征主题 · 显像管特效',
  purpose: 'Black-red Long March theme: independent theme, appearance toggle, logo, CRT effect and full icon set.',
  code: {
    host:   host.js の全文,
    client: client.js の全文,
  },
})
```

その後 `cordis_run` でアクティベートします（承認ポリシーが `ask` の場合、初回は
ユーザー承認が必要です）。

### 3. テーマ切り替え（任意）

有効化後、**設定 → 一般** の Appearance 行の下に「長征テーマ · 黒紅」があります。
「有効化」で黒紅パレットを適用、「無効化」でネイティブのダークテーマに戻します。

## 既知の制限と保守メモ

1. **テーマ切り替えは永続化されません**：動的プラグインのインメモリ状態です。ページを
   リロードすると永続化されたテーマ設定（dark/light）に戻るため、外観行で
   「長征」を選び直してください（プラグイン自体はセッション中ずっと動作）。ライト/ダークへ
   戻すと長征のスタイルと UI はすべてアンロードされ、外観行のみ残ります。
2. **CSS-module クラス名への依存**：枠なしブランド、ヒーロー見出し非表示、フォルダアイコン
   差し替え、直角、赤コントロールなどのルールは製品のクラス名の `_local` 部分
   （例 `hash_brand`、`hash_folder`、`hash_titleGroup`、`hash_turnStatus`、
   `hash_triggerRow`、`hash_sectionHeader`、`hash_newSession`、`hash_modes`、
   `hash_trailing`）に依存します。対象 dsh バージョンでクラス名が変わると該当ルールは
   黙って失效します。**スロット機能とテーマ色は影響を受けません**。不要なら
   該当 CSS 行を削除してください。
3. **ツールカードの置き換え**：read/glob/grep/read_image/write/edit/todo_write のカードは
   最小限のテーマカードに置き換わります。ネイティブのリッチカード（diff、画像など）を
   残す場合は `client.js` の `tool.call.toolview` 節から該当キーを削除してください。
4. **`redo.png` は未使用**：アンドゥ/リドゥには利用可能なスロットやサービス API が
   ありません。設定行のアイコン一覧にのみ表示されます。
5. **適用範囲**：赤/黒/直角ルールは `body[data-ds-dark-theme]`（ダークパレット、
   テーママーカー付き）で有効になります。ライトテーマでは、テーマ有効時に登録された
   スロット UI のみが存在します。
6. **承認**：新環境では初回に Client コードのユーザー承認が 1 回必要です
   （承認ポリシーが `ask` の場合）。
